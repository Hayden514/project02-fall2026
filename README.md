# Project 2: TODO App

This is my CSCI 338 Project 2 for Fall 2026 at UNC Asheville.

I am building a TODO application that lets users manage their tasks through a web interface.

The project uses React for the frontend, FastAPI for the backend, and PostgreSQL for the database. Docker Compose will be used to run the services together.

## Project Structure

- `backend/` contains the FastAPI application.
- `database/` contains the database setup.
- `ui/` contains the React frontend.

## Development

I am building and testing the application locally before deploying it to Railway.
